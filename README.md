# MotionGit Skill

把已完成的视频工程提炼、打包为可复用的 `.motion` 模板。

将下面一句话和工程一起交给 AI 助手：

> 请读取并使用 MotionGit Skill（https://github.com/adunext/motiongit-skill），将我提供的已完成视频工程提炼、打包成可复用的 .motion 模板。

助手从 [SKILL.md](SKILL.md) 开始，获取并校验官网当前 Skill，再按完整说明处理工程。这里提供稳定入口，工具和完整指南以官网下载包为准，避免维护多份过期副本。

[官网入口](https://motiongit.com/skill) · [手动操作](https://motiongit.com/skill/manual) · [当前完整 Skill 下载](https://motiongit.com/skill/motiongit-skill.zip)

## English

Give your AI assistant the finished project and this sentence:

> Read and use MotionGit Skill (https://github.com/adunext/motiongit-skill) to extract and package my finished video project as a reusable .motion template.

Start with [SKILL.md](SKILL.md). It points to the current official bundle and its verification steps. The assistant needs access to the actual project and local execution tools. Existing personal templates follow their own verified package instructions; do not share their private credentials.
